# Studio Policy: Productization

- `0.1.x` is prototype or pre-release. Version strings never advance phases.
- Production starts only after concept and plan approval plus a passed prototype or an explicitly recorded skip with risk.
- Vertical Slice proves a representative final-quality journey, production structure, art pipeline, and performance.
- Content Complete removes placeholders and completes release scope.
- Alpha proves full-flow stability, references, performance, localization integrity, and crash-free smoke.
- Beta proves target-platform preflight, icon, localization, crash/error, known-issue, and regression readiness without automatically packaging.
- Release Candidate locks final evidence and known issues. Release requires final smoke and complete verified scope.
- `production/scope/release-scope.json` is the explicit completeness set for features, content, tutorial, UI, configuration, audio, art, localization, operations, and builds.
- Gates parse structured evidence; file presence, subjective polish, or a visually improved prototype cannot pass.
