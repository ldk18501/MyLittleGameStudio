# 2D 角色动画美术生产规则

## 目的

本规则只适用于正式 2D 角色的骨骼动画、刚性分件、Sprite Skin 蒙皮，以及包含骨骼部分的混合动画。它解决效果图方向丢失、头身比漂移、AI 拆件重复、关节错位、Sorting 错误以及 Unity Prefab 无法还原视觉目标的问题。

纯帧动画继续执行 MLGS 原有的逐帧提取、基线、轮廓和帧一致性规则，不需要本合同。普通静态角色立绘、头像、图标、UI、场景资源和不参与骨骼动画的单张 Sprite 也不进入本规则；只有资源清单的 `visualComponent.generationUnit` 为 `skeletal-character`、`mesh-skin-character` 或 `hybrid-skeletal-character` 时，本规则失败关闭。

## 核心原则

- 效果图定义最终风格、动作语言和游戏内观感，不直接充当骨骼拆件源。
- 骨架、部件拓扑、Pivot、Socket、Sorting 和接缝归属是生产数据，不能由生图模型在拆件阶段临时猜测。
- 视角、朝向和头身比必须在生成前锁定。正面、侧面、四分之三侧面是不同生产视图，不能因共享骨架而互相替换。
- 生图只负责合同约束内的视觉内容。AI “透明爆炸拆件图”只能作为草稿，不得成为正式切图、骨骼或 Prefab 的规范来源。
- 共享动画先定义方向专用的共享 Rig Profile，再让角色适配该骨架；禁止从任意效果图重新生成一个通用正面骨架。
- 标准姿势下，每个可见语义区域只能有一个正式所有者。只有合同声明的接缝覆盖带允许部件重叠。
- Unity 中的 Pivot、骨骼层级、局部坐标、Sorting 和 Sprite Swap 必须从合同确定性接线，不能按包围盒中心或肉眼猜测。

## 动画方案选择

Art Director 与 Technical Artist 必须在角色正式生成前选择以下一种方案，并记录选择理由：

| 方案 | 适用情况 | 主要限制 |
|---|---|---|
| `skeletal-cutout` | 装备换装、复用动作、轻中度肢体运动 | 极限姿势和衣物扭转容易产生纸片感 |
| `mesh-skin` | 连续弯曲、减少肘膝硬接缝 | 需要网格、权重和变形验证 |
| `hybrid` | 战斗角色、待机/移动复用骨骼、攻击使用替换帧 | 需要同时管理 Rig 与 Sprite Swap |

如果评估后选择纯帧动画，立即退出本规则并回到既有逐帧生产流程；不得因为本规则存在而为帧动画额外创建骨骼合同。

下列情况默认选择 `hybrid`，或者改走不受本规则影响的纯帧动画流程，除非代表性试产证明纯骨骼可以达到目标：

- 躯干明显扭转或前后肢体频繁交叉。
- 武器攻击包含强透视缩短、夸张弧线或轮廓重构。
- 长衣摆、披风、裙甲、肩甲或头发需要在动作中改变前后关系。
- 目标图是侧身或四分之三侧身动作，而非正面中性姿势。

## 必需合同

每个正式动画角色必须有一个项目内文件：

```text
design/art/characters/<character-id>.animation.json
```

文件遵循 `.mlgs/character-animation-contract.schema.json`，并至少锁定：

- 视觉目标 ID、动画方案、配方 ID、正式生产视图。
- 头身比、总像素高度、脚底基线和允许误差。
- 效果图、方向专用姿势引导图、同视角 Rig Master、骨架叠加图和标准姿势。
- 骨骼父子关系、归一化关节坐标和旋转范围。
- 部件的骨骼、可见区域所有权、源图、蒙版、Pivot、Socket、Sorting 和接缝策略。
- AI 生成限制、隐藏区域补画方式和 prompt preserve/avoid 锁。
- 视角、比例、静止重建、部件归属、上下肢极限、接缝、帧一致性和游戏轮廓测试。
- Unity Renderer、确定性组装、Prefab、骨骼根节点和 Game View 证据。

## 正式源图与拆件

1. 先批准与玩法方向一致的 Rig Profile、方向专用姿势引导图和标准姿势。
2. 使用批准效果图、姿势引导图和 Rig Profile 生成或绘制完整 Rig Master。
3. 骨架叠加图必须来自同一张 Rig Master 上的确定性坐标，不得让模型重新绘制角色或改变视角。
4. 使用作者图层、人工分层或确定性蒙版分割可见像素。
5. 只允许在预先声明的蒙版内补画衣物下方、关节后方等隐藏区域。
6. 从蒙版和坐标导出部件；禁止把生成式爆炸拆件图直接当作规范切片。
7. 在进入 Unity 前重新合成标准姿势，并与 Rig Master 对比。

### 部件所有权

- 躯干、上臂、前臂、手、肩甲、袖口、裙甲和腿甲必须逐项指定所有者。
- 躯干若拥有完整袖子，上臂资源不得再次拥有同一袖子；若肩甲独立，躯干和上臂都不得重复绘制肩甲主体。
- `visibleRegionId` 在同一角色中必须唯一，防止“躯干上臂”和“独立上臂”同时出现。
- `exclusive` 部件不得声明重叠所有权。
- `declared-overlap` 必须列出互相覆盖的部件和接缝用途；重叠只用于隐藏旋转接缝，不得形成第二套肢体。
- 大腿应延伸到衣摆或裙甲下方，小腿应延伸到护膝/靴筒下方；覆盖方向和 Sorting 必须固定。

## Prompt 与内置配方

MLGS 内置配方位于 `templates/art-recipes/`，初始化项目时复制到 `design/art/recipes/`。配方负责稳定的生产步骤、提示词核心、负面约束、能力要求和验证集合；项目的视觉目标、`styleLock`、角色设定和合同数据再注入配方。

正式动画 prompt 必须：

- 使用批准效果图和 Rig Master 作为真实图片输入。
- 复制角色动画合同的 `promptLock` 快照。
- 明确写出生产视图、朝向、头身比、标准姿势和本次只允许改变的内容。
- 重复配方与合同中的所有 preserve/avoid 规则。
- 明确禁止正面化、镜头重置、重复肩膀/上臂、重新设计服装层级、额外肢体和生成式爆炸拆件。
- 分别为 Rig Master、蒙版补全、替换部件和动作帧生成 prompt，不能用一个自由文本 prompt 包办全部阶段。

如果当前生图能力不支持所需的姿势参考、蒙版编辑或一致性编辑，能力清单必须标记为 `missing`/`blocked`，然后改用人工分层、逐帧方案或缩小动画方案；禁止摸索式连续重抽并把偶然结果当生产规范。

## Unity 接入

- 刚性分件使用合同中的局部坐标、Pivot、Socket 和 Sorting 构建。
- 连续弯曲优先评估 Unity 2D Animation 的 Sprite Skin/网格权重；刚性装甲和武器保持独立层。
- `hybrid` 角色明确哪些动作使用骨骼、Mesh、部件换图、整帧替换和独立 VFX。
- 近侧/远侧肢体、交叉手臂、武器和衣摆的 Sorting 变化必须是动画数据或显式 Sprite Swap，不能依赖运行时偶然层级。
- Prefab Builder 必须幂等：同一合同与源文件重复构建应得到相同骨骼路径、局部坐标、Renderer 和 Sorting。
- 不得用 Unity Transform 微调掩盖错误源图。若标准姿势无法重建，应退回 Rig Master 或部件拓扑阶段。

## 失败关闭门禁

动画角色在以下条件全部通过前不得进入对应生命周期：

- `prompt-ready`：合同至少为 `specified`，视角、比例、方案、配方和 prompt lock 完整。
- `generated`：同视角 Rig Master 与骨架叠加图已批准，效果图没有被重新解释成其他方向。
- `processed`：部件所有权唯一，蒙版和隐藏补画可追溯，标准姿势重建、上下肢极限和接缝测试通过。
- `referenced`：Prefab 由合同确定性构建，骨骼路径、Pivot、Sorting 和真实场景引用存在。
- `approved`：所有合同测试通过，Game View 与目标对比通过，Art Director 与 QA 均为 `pass`。

任一 `unavailable`、`pending`、`fail`、错误视角、错误头身比、重复语义部件、未声明重叠、Prefab 手工猜测接线或缺少真实 Game View 证据都失败关闭。
